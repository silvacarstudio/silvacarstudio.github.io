SILVA CAR STUDIO — WEB FÁCIL DE MODIFICAR

NO NECESITÁS EDITAR EL HTML.

1) Abrí config.js.
2) Ahí están textos, colores, tamaño del logo, WhatsApp, Instagram y todas las fotos.
3) Para cambiar una foto, poné el nuevo archivo en images/.

LOGO:
- images/logo.png
- logoDesktop: 145
- logoMobile: 120

Si querés el logo más grande, cambiá esos números a 170, 190, etc.

FOTOS:
hero.image = "images/hero.jpg"
about.image = "images/about.jpg"
gallery.images = ["images/work-1.jpg", ...]

La estructura está separada para que puedas modificar contenido sin tocar el diseño.
